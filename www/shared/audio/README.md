# Shared audio extras

Three syllable recordings that 拼音闯关 does not host, used by 龙语群岛:

- `cmn-diao1.mp3`
- `cmn-kang1.mp3`
- `cmn-ei2.mp3`

Source: [hugolpz/audio-cmn](https://github.com/hugolpz/audio-cmn) 64k syllabs (`cmn-{key}.mp3`).
Speaker: Chen Wang. License: CC BY-SA.

Other pinyin syllables are served from `/pinyin/audio/` (the hashed files already used by 拼音闯关).
Neutral-tone recordings (`*5`) are not included; the games use a Mandarin TTS voice when one is available.
