# 拼音闯关（www.lucca.top/pinyin/index.html）

源文件在 `src/`，生成的静态页在 `www/pinyin/`，由 `.github/workflows/publish-pinyin.yml` 上传到 `lucca-www/pinyin/`。

## 题库
- 音节表：Unihan `kTGHZ2013`（《通用规范汉字字典》，覆盖 8105 字），共 1296 个带调音节（409 个音节）。
- 题库收 1242 个带调音节、401 个音节。没收：34 个轻声、ê/m/n/ng 叹词音节、无录音的 yō，以及 `excluded_verify.json` 里核对没通过的 10 个。

## 玩法（第三版）
- **拼音认字**：挖开矿石，露出一个多半还不认识的常用字和它的拼音，孩子自己读出来；可以点音符听录音对照（录音只是参考），再点绿勾或红叉自评。从露出到第一次操作（点喇叭或判对错）的时间算反应时间；先听了录音再判对的不算「快」。每局前两题是只有拼音的热身。
- **按音找字**：看拼音、自动播读音，从 4 个字里点出对的。4 个选项全是孩子学过的字（课本字表＋常用虚词），干扰字是读音相近（声调、前后鼻音、平翘舌、b/d 等）或同声旁的字，答完再播一遍读音。
- **看字选拼音**：给一个学过的字，从 4 个拼音里点出对的。错的 3 个是常见拼错：声调、an/ang 类前后鼻音、z/zh 类平翘舌、少写或写错介音、b/d、p/q、j/q/x 后的 ü/u、ui/iu、ie/üe、整体认读写法（yi/i、wu/u、yu/ü 等），每题最多一个只差声调的；错的拼音一定不是这个字的任何读音（多音字也查过）。首页有单独入口，也混在普通练习里；题目上不播读音，答完才播。
- **看图选拼音（我的世界词语）**：56 个我的世界角色、动物、物品、方块和食物（村民、末影龙、苦力怕、僵尸、骷髅、蜘蛛、末影人、史莱姆、蝙蝠、牛、猪、羊、鸡、马、狼、猫、鱼、蜜蜂、熊猫、钻石、绿宝石、红石、剑、镐、铁斧、弓、箭、铁、金、煤、地图、时钟、矿车、圆石、原木、草方块、仙人掌、树、花、岩浆、火把、床、门、宝箱、工作台、熔炉、炸药、传送门、小屋、苹果、面包、蛋糕、西瓜、南瓜、鸡蛋、牛奶），给图选整词拼音（如 kǔ lì pà）。图全部是程序画的原创像素图，按游戏里的样子重画：生物用正面（头 8、身 12、腿 12 的比例，村民大鼻子一字眉绿眼棕袍抱臂，苦力怕斑驳绿色四条腿，僵尸青衣蓝裤平举双手，骷髅拿弓，末影人细高紫眼），动物侧面，方块用 16×16 程序生成的纹理拼成背包里那种立体小方块，物品是斜放的背包图标；没有用任何 Mojang 原版贴图文件。错的 3 个各只改一个音节，改成这个音节常见的拼错（如 kǔ lì bà、kū lì pà、kǔ nì pà），而且改出来的音节不能是这个字的任何读音（多音字如 钻 zuān/zuàn、车 chē/jū、把 bǎ/bà、炸 zhá/zhà 都排除）。只收不带轻声的词（石头、木头、箱子、房子这类轻声词没有录音，换成圆石、原木、宝箱、小屋）；每个字的读音在 Unihan 里、整词读音和 pypinyin 词典一致，构建时自动核对。答对后显示汉字，并按音节连读录音。混在普通练习（约一成）、看字选拼音（约三成）和冒险三章（34%～40%，矿洞多出方块物品、守村多出生物、末地多出怪物物品）里。答对算词里每个音节练对一次（不算「快」），答错只记被改的那个音节。
- **冒险闯关**（替换原来的气球闯关）：三章，后一章要先打通前一章。① 矿洞下潜：答对一题挖下一块，草→泥土→石头→铁矿→金矿→钻石，12 题；② 守护村庄：怪物从右边走向村庄，答对就射箭赶走它，超时怪物冲到篱笆扣一颗心，10 题；③ 末地决战：答对一题射末影龙一箭，10 题打空血条；场景照游戏画：黑色虚空、末地石、黑曜石柱顶上的末地水晶（基岩上的火 + 两层会转的玻璃框 + 粉色核心），最近的水晶会放治疗光束连到末影龙，答对第 1、4、7 题时各打爆一颗水晶，三颗都爆了光束就断；末影人（有一只抱着草方块），返回传送门（基岩井 + 中间插火把的基岩柱），打败末影龙后龙蛋落在柱顶。末影龙是黑色鳞片身体、紫眼睛、大翼膜翅膀、背上到尾巴一排刺、长尾巴。题型混着出：看图选拼音（我的世界词语）34%～40%，其余约一半看字选拼音、一半按音找字。场景里有树、工作台、宝箱、牛、猪、火把、蝙蝠、猫、鸡、羊、末影人、传送门等原创像素元素。每题有时间条（第一、二章 13→8 秒，第三章 12→7.5 秒），3 颗心；点错只扣这题的分不扣心，同一题还能接着选。挖到的方块、经验球、龙蛋收进背包。画面全是程序画的原创像素图，音效用 Web Audio 合成。
- **虚词和分类轮换**：「这、那、就、也、在、不、很、都、过、把、被、给、跟、对、从、向、再、又、才、还、和、但、因、所、如、果、可、比、最、太、谁、哪、怎、什、啊、呀、哇、地、得、没、以」等 40 个常用虚词音节优先出成按音找字题；轻声的「的、了、着、呢、吧、吗、么」没有录音，只当干扰字。音节分成单韵母、复韵母、前后鼻韵母、三拼（介音＋韵母，如 jia、guo、xiang）、整体认读 16 个五类，一局里按「虚词、三拼、整体认读、虚词、鼻韵母、三拼、复韵母、虚词、整体认读、单韵母」轮着补新音节，三拼和整体认读出得多；家长页有每类的覆盖和掌握情况。
- 所有玩法都写进同一套掌握度（石头→铁→金→钻石）和间隔复习，爸爸抽查读错会退回铁。存档 key 仍是 `lucca-pinyin-v1`，`v:2`，第三版只新增字段（`camp` 冒险进度、`catTurn`、`pickSeen`、`words` 词语答题记录），老存档原样保留；第一版「听音选拼音」的记录在 `legacy` 字段。

## 字库（scripts/build_chars.py → chars_data.js）
- 读音：Unihan `kTGHZ2013`。只有一个规范读音的字直接用；多音字只在 `kHanyuPinlu` 里这个读音占八成（认字）或九成（找字、看字选拼音）以上时才用；虚词取它最常用的非轻声读音（占非轻声用法七成以上、全部用法两成以上）。
- 「学过的字」：人教版一年级、二年级上册课本字表（child-literacy 的 char_lists）加上面那批常用虚词。按音找字的 4 个选项、看字选拼音和看图选拼音的字都只从这里取。
- 认字只用最常用的 1000 个字（按 `kHanyuPinlu` 总频次排，限《通用规范汉字表》内），并排除学过的字，没有合适字的音节只做纯拼音热身。
- 干扰字一律排除任何读音里含目标音节的字（多音字不会出现两个对的答案）；打分优先同音不同调、前后鼻音互换、易混声母互换（b/d、p/q、z/zh、n/l 等），其次同韵母、同声母，同声旁（`kPhonetic`）再加分。
- 覆盖：218 个带调音节有认字用字（共 272 个字），670 个有找字题（1075 个答案字），486 个两样都没有、只做纯拼音热身。按类：单韵母 238 个音节（找字 132）、复韵母 326（171）、前后鼻韵母 381（202）、三拼 239（117）、整体认读 58（48）。
- 第二版的 `find_lock.json` 已删除：找字题改成全部从学过的字里出，按上面规则每次构建确定生成（排序固定）。

## 读音核对（scripts/）
1. `prep_audio.py`：裁静音、统一音量。
2. `asr_sv.py`、`asr_pf.py`、`score_asr.py`：SenseVoice 和 Paraformer 两套识别，看识别出的字能不能读成目标音节。
3. `ctc_score2.py`、`contrast.py`：同一朗读者的易混对（b/d、z/zh、n/l、an/ang、声调等）做 CTC 对比，目标录音应比对方录音更像目标。
4. `f0_praat.py`、`tone_cls.py`：Praat 声调曲线加交叉验证分类，和标注声调对比；不一致的逐个看了曲线。
结果见 `verification_report.json`。

## 性能与稳定性（手机端）

- 首页云朵用 `translate` 动画，第 3 章治疗光束和答题时间条只改 `transform`，不再每帧重排；第 3 章光束只保留一条 rAF 循环，离开冒险画面就停。
- 矿石贴图的随机种子限制在 16 个以内，缓存能复用，不再每题新画 PNG。
- 解码后的音节录音只在内存里留最近 120 个（mp3 文件本身有长缓存）。
- 拼音粗体字不再首屏 preload，页面加载完后空闲时再下；百度统计也改到加载完再插。
- 冒险每局有编号，退出或重开后旧局的延时、箭和掉落动画回调都不再执行；练习中途回首页，旧局的跳题延时不会影响新局。

## 重新生成
在工作目录准备好 audio-cmn 的 `64k/syllabs`、Unihan、Commons 替换录音后，依次运行 `syllables.py`、`prep_audio.py`、`build_data.py`、`build_chars.py`、`build_site.py`，再把 `site/pinyin/` 复制到 `www/pinyin/`。
